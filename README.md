# MediFlow — AI-Powered Hospital Management System

MediFlow is a modern hospital management system designed to simplify healthcare workflows by bringing patient information, appointments, and doctor interactions into one platform. The project aims to explore how AI can assist authorized users in finding information from hospital documents.

> **Project status:** Frontend landing page completed. Core hospital management features are under development.

## ✨ Planned Features

- **Patient Management** — Organize patient profiles and visit histories.
- **Appointment Management** — Schedule and manage hospital appointments.
- **Doctor Workspace** — Help doctors manage schedules and patient consultations.
- **Role-Based Access** — Provide different experiences for administrators, doctors, and patients.
- **AI Document Assistant** — Help authorized users find information in hospital documents with source references.

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gourab2307/mediflow.git
   ```

2. Navigate into the project:

   ```bash
   cd mediflow
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173/`.
